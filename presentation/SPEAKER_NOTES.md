# Kakashi Manager Briefing — Speaker Notes

## 1. Kakashi

Open with the outcome: Kakashi lets teams use AI agents without handing those
agents raw sensitive records by default. Today you will prove that locally.

## 2. The risk has changed

The issue is not only a human attaching the wrong spreadsheet. Agents can read,
query, and transmit autonomously. Prevention belongs directly in the transfer
path, before the payload leaves the controlled environment.

## 3. Three layers

Engine protects one resource. Reach scales that engine to data estates and
databases. Guardian adds context and an explicit release decision. Emphasise
that organisations can adopt the layers incrementally.

## 4. Coverage

Mention representative categories, not every pattern. Typed tokens are often
best for AI analysis because repeated values remain distinguishable without
revealing the originals.

## 5. File case

Run `./demos/01-file-protection.sh`. Explain exit code `1`: findings are a
successful detection result, not a crash. Point out that audit output is hidden
because it is intentionally unsafe for an agent-visible terminal.

## 6. Folder case

Run `./demos/02-folder-compliance.sh`. Open both HTML reports. The report maps
technical findings to PDPL-oriented context, but the tool does not claim to
provide legal certification.

## 7. Database case

Run `./demos/03-database-protection.sh`. The offline adapter makes the live demo
reliable. Production drivers use the same local masking path. Stable tokens keep
analytics useful across rows.

## 8. Guardian case

Run `./demos/04-guardian-decision.sh`. Contrast the two outcomes: verified
transformation for a legitimate analytics task, then human approval for a
credential-bearing request. The agent never mints its own approval.

## 9. Sidecar case

Run `./demos/05-agent-sidecar.sh`. The random port proves the process really
starts. The service is loopback-only; “zero outbound calls” does not mean
“Kakashi never uses a local socket.”

## 10. Government value

Tie the features to governance outcomes: sovereignty, minimisation, purpose
limitation, and traceability. The Arabic experience reduces adoption friction
for bilingual teams.

## 11. Limitations

This slide builds credibility. Kakashi reduces accidental disclosure risk; it
does not replace IAM, classification, contracts, retention, incident response,
or legal interpretation.

## 12. Proof

Stress that tomorrow’s artifacts are generated by assertions. A PASS means the
expected safety invariant was checked, not merely that a command printed output.

## 13. Rollout

Recommend a bounded pilot first. Measure false positives and utility as well as
raw finding counts. Put an approval owner and exception path in place before
expanding.
