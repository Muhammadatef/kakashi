طبقة خصوصية محلية تعيش *داخل* Claude Code و Cursor و Codex CLI وأكثر من 20 وكيل ذكاء اصطناعي.

تُخفي مفاتيح API وكلمات المرور والأسرار والبيانات الشخصية عبر **PDF و Word و Excel و JSON و .env** وأكثر من 45 صيغة أخرى — *قبل* أن يراها وكيلك.

**30 ثانية للتثبيت. لا شيء يغادر جهازك. أبداً.**

## المشكلة

كل يوم، في كل فريق تطوير، يفعل شخص ما هذا:

```bash
# "دعني أسأل Claude لماذا يفشل هذا الاستعلام..."
cat quarterly_report.xlsx | claude
```

أو هذا:

```python
# "Cursor، أصلح خطأ المصادقة في هذا الملف"
# (الملف يحتوي على كلمة مرور قاعدة البيانات الإنتاجية)
open("config/settings.py")
```

أو هذا:

```bash
# "ChatGPT، أعد كتابة هذا الاستعلام SQL"
# (الاستعلام يعمل على سجلات عملاء حقيقيين)
```

داخل هذه الملفات — دون أن تلاحظ، دون تحذير، دون أي احتكاك — توجد أشياء لا ينبغي أن تغادر جهازك أبداً:

```
postgresql://admin:Pr0d_P@55word!@10.128.3.4:5432/customers
sk-proj-aBcDeFgHiJkLmNoPqRsTuVwXyZ123456789
784-1990-9999999-0
admin@example.com
+971-50-123-4567
AE070331234567890123456
```

**لقد سافرت للتو إلى خادم طرف ثالث. بنص واضح. دون تراجع.**

- GitLeaks لن يكتشفها — إنه يفحص تاريخ git فقط
- TruffleHog لن يكتشفها — يعمل في CI بعد وقوع الضرر
- بيئة التطوير لن تكتشفها — ليس لديها فكرة عما تعنيه "الحساسة"

## الحل

Kakashi يُثبَّت كـ **مهارة** داخل وكيل الذكاء الاصطناعي مباشرة. ليس تطبيقاً منفصلاً. ليس امتداد متصفح. ليس حاوية Docker. مهارة — موجودة عند فتح Cursor، موجودة في Claude Code، موجودة أينما تعمل.

```
┌─────────────────────────────────────────────────────┐
│  التدفق التقليدي                                    │
│  أنت → [لصق ملف] → وكيل ذكاء اصطناعي → LLM خارجي   │
│  الأسرار تسافر إلى خادم طرف ثالث.                   │
│                                                     │
│  مع Kakashi                                         │
│  أنت → [لصق ملف] → Kakashi يفحص → يقنّع →           │
│         وكيل ذكاء اصطناعي → LLM خارجي              │
│  فقط رموز [TOKEN_n] تعبر السلك.                    │
└─────────────────────────────────────────────────────┘
```

## التثبيت

سطر واحد. يكتشف كل وكيل على جهازك. يُثبت لهم جميعاً.

```bash
# macOS · Linux · WSL · Git Bash
curl -fsSL https://raw.githubusercontent.com/Muhammadatef/kakashi/main/install.sh | bash
```

```powershell
# Windows (PowerShell 5.1+)
irm https://raw.githubusercontent.com/Muhammadatef/kakashi/main/install.ps1 | iex
```

أو عبر npm:

```bash
npm install -g @muhammadatef/kakashi
```

**~30 ثانية. يتطلب Node ≥ 18. آمن لإعادة التشغيل.**

## كيف يعمل

**1. الفحص** — انظر ما هو حساس قبل أن يتحرك. الافتراضي هو **الأعداد فقط**، حتى لا تتسرب أي قيم سرية إلى stdout (أو، إذا كان وكيل الذكاء الاصطناعي يقرأ الإخراج، إلى نافذة سياق الوكيل).

```bash
kakashi scan --lang ar quarterly_report.xlsx
```

**2. التقنيع** — استبدل في المكان، أعِد بناء الصيغة الأصلية.

```bash
kakashi mask quarterly_report.xlsx
```

**3. مشاركة آمنة** — *Word يبقى Word. Excel يبقى Excel. PDF يبقى PDF.*

## يعمل داخل وكيلك

ست أوامر Slash يتم تثبيتها مباشرة في محادثة الوكيل — Claude Code و Cursor و Codex CLI و Windsurf يحصلون على المجموعة الكاملة:

```
/kakashi              فعّل وضع الخصوصية للجلسة
/kakashi-scan <path>  الأعداد فقط — بدون معاينات (آمن للوكيل، افتراضي)
/kakashi-mask <path>  اكتب masked_<file> بجانب الأصل
/kakashi-audit <path> التخطيط الكامل من الأصل → البديل (يكشف الأسرار عمداً)
/kakashi-stats        إحصاءات الجلسة التراكمية
/kakashi-list         كل أنماط الاكتشاف النشطة
```

## أكثر من 50 صيغة ملف

Kakashi يقرأ ويقنّع و**يعيد بناء** الصيغة الأصلية. الملف الذي تحصل عليه هو ملف `.docx` حقيقي — ليس مجرد نص خام.

### الوثائق والبيانات

| الصيغة | القراءة | التقنيع | إعادة البناء | الحالة |
|---|:---:|:---:|:---:|---|
| Excel `.xlsx` `.xls` | نعم | نعم | `.xlsx` كامل | **مستقر** |
| CSV / TSV | نعم | نعم | نفس الصيغة | **مستقر** |
| JSON / JSONL | نعم | نعم | نفس الصيغة | **مستقر** |
| YAML / TOML | نعم | نعم | نفس الصيغة | **مستقر** |
| Markdown | نعم | نعم | نفس الصيغة | **مستقر** — يدعم اللغة العربية والاتجاه من اليمين إلى اليسار |
| Word `.docx` | نعم | نعم | `.docx` كامل | **أفضل جهد** — يدعم النص العربي طالما لم ينقسم بين حدود التنسيق |
| PowerPoint `.pptx` | نعم | نعم | `.pptx` كامل | **أفضل جهد** |
| PDF `.pdf` | نعم | نعم | `.md` مُقنّع | **نص فقط** |

## قانون حماية البيانات الشخصية الاتحادي رقم 45 لسنة 2021

Kakashi يدعم مباشرة الامتثال لقانون حماية البيانات الشخصية بمنع النقل غير المصرح به للبيانات الشخصية عبر الحدود من المصدر. تخريطة فئات الاكتشاف لدينا تشير إلى مواد محددة من قانون حماية البيانات الشخصية:

- **المادة 1** (تعريفات البيانات الشخصية) — كل البيانات الشخصية
- **المادة 15** (البيانات الشخصية الحساسة) — الهوية الإماراتية، جواز السفر، بطاقة الائتمان، IBAN
- **المادة 20** (أمن البيانات الشخصية) — كل بيانات الاعتماد
- **المادة 21** (الإبلاغ عن الانتهاكات) — تسرب بيانات الاعتماد
- **المادة 22** (النقل عبر الحدود) — أي معرف يمكن أن يحدد الهوية

قم بإصدار تقرير امتثال جاهز للتدقيق باللغة العربية:

```bash
kakashi scan-dir ./project --lang ar --format html -o report.html
```

## لماذا "Kakashi"؟

> *كاكاشي هاتاكي. النينجا الناسخ. مقنّع دائماً. ينسخ كل تقنية يواجهها. يتكيف مع أي بيئة.*

الأداة **تُقنّع ما ينبغي أن يبقى مخفياً** — كما لا يُظهر الشخصية وجهه أبداً.
**تنسخ نفسها** إلى كل وكيل تجده — كما ينسخ النينجا كل جتسو يراه.
**تتكيف** مع أي صيغة، أي نظام تشغيل، أي أداة — لأن هذا ما يفعله نينجا النسخ.
